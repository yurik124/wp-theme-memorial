МЕМОРИАЛ — ОБРАБОТКА ФОТО НА КОМПЬЮТЕРЕ (Windows 10/11)

Делает то же, что экран «Мемориал → Обработка фото» на сайте, но у вас на компьютере,
без интернета (кроме первого запуска) и без GitHub Actions:
цвет, единый светлый фон товаров, одинаковые пропорции и обрезка по предмету,
логотип в правом нижнем углу, удаление EXIF, перевод в sRGB, отчёт о плохих фото.
Исходные фото никогда не меняются.


КАК ПОЛЬЗОВАТЬСЯ

1. Распакуйте архив в любую папку (например, «Документы\Мемориал-фото»).
2. Положите фото в папку «Фото», в подпапки по видам:
   Венки, Корзины, Гробы, Кресты, Оградки — товары, фон заменяется на единый;
   Памятники — товары, свой фон остаётся;
   Работы — фото «Наших работ»;
   любые другие папки — как «Работы».
3. Двойной щелчок по «1 Предпросмотр».
   Откроется страница в браузере: по 3 фото из каждой папки, ползунок «до / после».
   Внизу — список плохих фото (маленькие, тёмные, размытые, повторы).
4. Не нравится — откройте «настройки.ini» (двойной щелчок, откроется в Блокноте),
   поменяйте, сохраните и снова «1 Предпросмотр».
5. Нравится — «2 Обработать». Готовые фото появятся в папке «Готово»
   с теми же подпапками и именами. Их и загружайте на сайт.
   Повторный запуск обрабатывает только новые и изменённые фото
   (и все — если поменялись настройки).


ПЕРВЫЙ ЗАПУСК

Нужен интернет и 5–10 минут: программа ставит себе Python-пакеты в папку
«программа\python» (систему не трогает). При первой замене фона она скачивает
модель (~180 МБ) в «программа\модель». Дальше всё работает без интернета.

Если Python на компьютере нет, программа попробует поставить его сама (winget).
Не получилось — скачайте Python 3.12 с https://www.python.org/downloads/
(при установке отметьте «Add python.exe to PATH») и запустите файл ещё раз.

Скорость: цвет, обрезка и логотип — доли секунды на фото;
замена фона — 3–10 секунд на фото (зависит от компьютера).


НАСТРОЙКИ (настройки.ini)

1 — включено, 0 — выключено. [Обработка] включено = 0 — выключить всё сразу.
Каждый раздел ([Цвет], [Фон], [Обрезка], [Логотип], [Очистка], [Отчёт]) включается отдельно.
По умолчанию — те же значения, что на сайте.

Логотип: знак «Мемориала» и слово «Мемориал» шрифтом сайта.
  цвет = белый — белый с мягкой тенью, виден на любом фото;
  цвет = как на сайте — зелёный знак, тёмное слово;
  название = 0 — только знак;
  свой_файл = путь к своему PNG с прозрачным фоном.


ВАЖНО ПРИ ЗАГРУЗКЕ НА САЙТ

Если фото уже обработаны этой программой, на сайте в «Мемориал → Обработка фото»
не включайте те же функции для этих фото (иначе цвет поправится второй раз,
а логотип встанет дважды). Проще всего: обрабатывать фото здесь, а на сайте
оставить обработку выключенной.

WordPress сам делает маленькие копии (карточки каталога) из загруженного фото —
логотип на них тоже будет, только мелкий. Если он мешает в карточках, выключите
логотип здесь и включите его на сайте: там он ставится только на большие копии.
