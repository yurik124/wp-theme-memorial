## Блоки в редакторе и значения для SEO (ветка `blocks-ux`, тема 5.0.1)

- **Группы блоков по назначению** вместо одной «Мемориал»: контакты; каталог и цены; услуги и информация; отзывы; оформление и кнопки; шапка, подвал и всплывающие; целые страницы (для шаблонов). Понятные названия: «Хлебные крошки», «Значок в круге», «Строка над шапкой: адрес и часы работы», «Каталог: товары раздела», «Карточка товара»… «Сетка услуг» и «Сетка пакетов» убраны из вставки (повторяют «Наши услуги» и «Пакеты похорон»; на страницах продолжают работать).
- **«Что показывать»** в настройках блока (`src/block-controls`): адрес строки над шапкой и галочки часов/ночной линии; раздел каталога (список вместо ввода названия) у «Каталог», «Список подразделов», «Фото товаров»; товар у «Карточка товара»; раздел у «Раздел каталога с сортировкой»; страницы у «Карточки разделов», «Полезно знать», «Все вопросы и ответы», «Наши услуги», «Кнопка-ссылка». Блок, который не нашёл данных на своей странице, показывает выбор прямо на месте; выбор меняется в настройках.
- **Карточки разделов**: по умолчанию — разделы своей страницы; можно выбрать разделы другой страницы (`roditel`) или страницы списком.
- **Сворачивание**: любой блок плагина сворачивается в редакторе в одну строку (кнопка на панели блока); в админке записи списков (пакеты, услуги, кладбища…) свёрнуты в строку с названием, «Свернуть все / Развернуть все»; состав пакета — компактными строками.
- **«Мемориал → Значения для текста и SEO»**: свои значения, цена «от»/«до» и число моделей раздела, цены из «Цены» и цены услуг; галочка «В SEO-плагин» — только отмеченные становятся переменными `%%mem_код%%`. Окно «Значение сайта» выбирает из списков (раздел, цена, услуга, «Моё значение», документ).
- **Главная и «Контакты»** в редакторе — без шапки и подвала (раскладка шаблона сохраняется), без отдельного поля заголовка.
- **Редактор**: блоки с плавным появлением больше не бывают невидимыми в редакторе; шапка и подвал в редакторе сайта на всю ширину; у всех паттернов есть категория.

## Memorial Modern 5.0.0 и Memorial Plugin 2.0.0 — переход на блоковую архитектуру

| Этап | Что сделано |
|---|---|
| 1. Каркас | Новые папки и префиксы (`memorial-theme`, `memorial-plugin`, `memorial_theme_`, `memorial_plugin_`), переключение со старых папок и откат, сборка `@wordpress/scripts`, PHPCS / ESLint / Stylelint, CI, режимы Яндекс Метрики |
| 2. Тема | `theme.json` v3, шаблоны и части, паттерны, варианты стиля; «Оформление» → стили сайта, меню → «Навигация» |
| 3. Блоки плагина | Блоки вместо шорткодов, «значения сайта» в тексте, перевод контента с предпросмотром и откатом, переменные SEOPress, Block Hooks, иконки в SVG Icon API, главная из блоков; удалены модули скорости |
| 4. Админка | DataViews / DataForm / `@wordpress/admin-ui` вместо `WP_List_Table`, PHP-форм и jQuery; панели полей в блочном редакторе |
| 5. Abilities и Command Palette | 12 способностей, их вызов из интерфейса, палитры команд и REST |
| 6. Стили и интеграция | Пресеты с запасными значениями, мост для чужих тем, загрузка ассетов только с блоками, кладбища на Interactivity API |
| 7. Безопасность, доступность, тесты | Поведение всех блоков на Interactivity API; IP не хранится, ограничения частоты; WCAG 2.2 AA (контраст, фокус, reduced motion, axe); PHPUnit |
| 8. Документация и релиз | Строки на английском и русский перевод (`.pot`, `.po`, `.mo`, JSON), `uninstall.php`, `readme.txt`, этот файл, `STANDARDS_REPORT.md`; справка «Шорткоды и блоки» удалена; версии 5.0.0 / 2.0.0 |
