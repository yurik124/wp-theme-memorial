# Автотесты сайта «Мемориал»

Тесты открывают сайт в настоящем браузере (Chromium) так же, как посетитель: на компьютере (1366×900) и на телефоне (Android, экран 320 px, сенсор). После запуска сам открывается отчёт со снимками страниц.

**Что проверяется**

- **Страницы** (из карты сайта):
  - открываются;
  - нет ошибок PHP и JavaScript;
  - нет «сырых» шорткодов `[mem_…]`;
  - у каждой страницы есть `<title>` и ровно один `<h1>`;
  - микроразметка без ошибок.
- **Вёрстка** на ПК и телефоне. По одной странице каждого вида: главная, каталог, раздел, товар, работы, отзывы, вопрос–ответ, цены, контакты. Для каждой:
  - ничего не вылезает за экран;
  - текст помещается: длинные слова и ссылки не растягивают страницу;
  - картинки загружаются;
  - нет гигантских блоков.

  Отдельно проверяется, что все страницы не шире экрана телефона.
- **Шапка и подвал:** логотип, телефон, меню на телефоне, ссылки на документы в подвале.
- **Блоки плагина:**
  - отзывы Rewio (сортировка, фильтр);
  - поиск по вопросам;
  - кнопки разделов каталога;
  - миниатюры «Наших работ» на ПК и телефоне;
  - карточки примеров работ.
- **Cookie и Метрика:** режимы плашки, UTM-метки убираются из адреса, а Метрика получает адрес с ними.
- **Окно «Перезвоните мне»:** открывается, проверяет поля, маска телефона, ссылки на согласие и политику.
- **Фото и скорость:** крупные фото не обрезаны, кэш страниц, сжатые стили и скрипты.
- **Админка** (если указан логин):
  - все пункты меню «Мемориал», «Каталог», «Наши работы» открываются без ошибок;
  - таблица товаров и список работ загружаются;
  - работает расшифровка шорткодов.

**Тесты ничего не меняют на сайте.** В админке они только открывают страницы, ничего не сохраняют. Запросы к Яндекс Метрике блокируются, поэтому статистика сайта не портится. Единственное исключение — отправка тестовой заявки, она включается отдельным флагом.

## Почему «страниц много»

Список страниц берётся из карты сайта. В ней все страницы, разделы каталога и каждый товар, а товаров сотни. Все товары сделаны по одному шаблону, поэтому **по умолчанию из товаров берётся выборка: 12 штук**, а страницы и разделы проверяются все. Проверить вообще все товары можно с флагом `--all-pages`, это заметно дольше.

## Установка (один раз, Windows)

1. Python 3.10 или новее с [python.org](https://www.python.org/downloads/). При установке отметьте **Add Python to PATH**.
2. Окружение лучше создать **вне Яндекс Диска**:

```
python -m venv C:\venvs\memorial
C:\venvs\memorial\Scripts\activate
cd C:\Users\ko4ki\YandexDisk\memorial_speshu\memorial-tests
pip install -r requirements.txt
python -m playwright install chromium
```

3. Для проверки админки создайте в папке `memorial-tests` файл `secrets.ini`:

```
[admin]
user = ваш_логин
password = ваш_пароль
```

Файл остаётся только на вашем компьютере: вся папка `memorial-tests` исключена из Git. Без этого файла тесты админки просто пропускаются. Если на сайте при входе капча или двухфакторный вход, тест сообщит, что войти не удалось.

## Запуск

```
C:\venvs\memorial\Scripts\activate
cd C:\Users\ko4ki\YandexDisk\memorial_speshu\memorial-tests
python -m pytest
```

Варианты:
```
python -m pytest -m "not slow"                        # быстро: без проверки всех страниц подряд
python -m pytest --all-pages                          # все страницы, включая каждый товар
python -m pytest --base-url https://memorialbel.ru    # рабочий сайт вместо тестового
python -m pytest -k admin                             # только админка
python -m pytest -k layout                            # только вёрстка
python -m pytest --headed --slowmo 300 -k works       # смотреть в окне браузера, замедленно
python -m pytest --submit-forms -k submit             # отправить тестовую заявку (придёт уведомление!)
python -m pytest --no-open                            # не открывать отчёт в конце
```

По умолчанию проверяется `https://memorialbel.test-handyhost.ru`.

## Что видно во время работы

```
  Сайт: https://memorialbel.test-handyhost.ru
  ✔ Шапка на ПК: логотип и телефон  (0.2 с)
  ✔ Меню на телефоне открывается  (0.9 с)
  ✘ Вёрстка не ломается: …  [Цены, телефон]  (1.8 с)
      → https://…/ceny/ — текст не помещается (длинное слово или ссылка): h1 «Политика конфиденциальности»
  – Настоящая заявка — придёт уведомление!  → нужен флаг --submit-forms
  Итого: ✔ 60 прошло, ✘ 1 ошибок, – 1 пропущено.
```

`✔` — прошло, `✘` — ошибка (сразу видно, где и что), `–` — пропущено (блока нет на сайте или нужен флаг).

## Отчёт

После запуска в браузере открывается `reports\<дата и время>\отчет.html`:

- итог и список всех проверок по разделам;
- снимки каждой проверенной страницы на ПК и телефоне — нажмите, чтобы открыть крупно;
- у ошибок — причина и кнопка «подробно».

Для каждой ошибки в папке `reports\<дата>\ошибки\` сохраняются:

- `screenshot.png` — вся страница в момент ошибки;
- `page.html` — код страницы, каким его видел браузер;
- `info.txt` — адрес, ошибки JavaScript, текст ошибки.

Старые папки в `reports` можно удалять.

## Когда запускать

После каждого обновления темы или плагина, сначала на тестовом сайте. Если всё зелёное, обновляйте рабочий сайт. Если что-то упало, а вручную всё выглядит нормально, пришлите мне вывод и `info.txt`.
