# Автотесты сайта «Мемориал»

Это проверки сайта в настоящем браузере (Playwright + pytest). Они открывают сайт, как посетитель, и проверяют:

- **Страницы:**
  - все страницы из карты сайта открываются;
  - нет ошибок PHP и JavaScript;
  - нет «сырых» шорткодов `[mem_…]`;
  - у каждой страницы есть заголовок и один `<h1>`;
  - микроразметка без ошибок.
- **Шапка и подвал:** логотип, телефон, меню на телефоне, ссылки на документы в подвале. Страницы на телефоне не шире экрана.
- **Блоки:**
  - отзывы Rewio (сортировка, фильтр);
  - поиск по вопросам;
  - кнопки разделов каталога;
  - миниатюры «Наших работ» на ПК и телефоне;
  - карточки примеров работ.
- **Плашка cookie и Метрика:** режимы «спрашивать» и «уведомлять», UTM-метки убираются из адреса, а Метрика получает адрес с ними.
- **Окно «Перезвоните мне»:** открывается, проверяет поля, маска телефона, ссылки на согласие и политику.
- **Фото и скорость:** крупные фото не обрезаны, кэш страниц, сжатые файлы.

Тесты ничего не меняют на сайте. Единственное исключение — отправка тестовой заявки, она включается отдельным флагом.

## Установка (один раз, Windows)

1. Установите Python 3.10 или новее с [python.org](https://www.python.org/downloads/). При установке отметьте **Add Python to PATH**.
2. Откройте эту папку в проводнике, в адресной строке наберите `cmd` и нажмите Enter.
3. Выполните:

```
pip install -r requirements.txt
python -m playwright install chromium
```

## Запуск

```
python -m pytest                                      # все проверки тестового сайта
python -m pytest -m "not slow"                        # быстро (~30 с): без обхода всех страниц
python -m pytest --base-url https://memorialbel.ru    # проверить рабочий сайт
python -m pytest --headed -k works                    # только «Наши работы», с окном браузера
python -m pytest --submit-forms -k submit             # отправить тестовую заявку (придёт уведомление!)
```

По умолчанию проверяется `https://memorialbel.test-handyhost.ru`. Адрес можно поменять параметром `--base-url` или переменной окружения `MEM_BASE_URL`.

## Как читать результат

- `.` — проверка прошла.
- `s` — проверка пропущена: на сайте нет такого блока или функция выключена. Причина написана внизу.
- `F` — ошибка. Ниже будет написано, на какой странице и что не так, например: `миниатюра слишком большая: 345px — стили блока не подключены?`.

## Когда запускать

После каждого обновления темы или плагина, сначала на тестовом сайте. Если всё зелёное, обновляйте рабочий сайт.

Если тест упал, а сайт вручную выглядит нормально, пришлите вывод теста, разберёмся.
