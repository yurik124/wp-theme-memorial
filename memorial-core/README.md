# Memorial Core — функционал сайта «Мемориал»

Плагин отвечает за **что сайт умеет**, тема Memorial Modern отвечает за **как сайт выглядит**.
Тема и без плагина выглядит полностью: шапка, логотип, меню, подвал, страницы, оформление. Плагин добавляет к ним данные и блоки: контакты, каталог, цены, отзывы, блоки главной страницы и так далее.
Плагин работает только с темой версии 3.0 и новее. Со старой темой он ничего не подключает, поэтому сайт не ломается.

## Как поменять

- **Новая настройка.** Допишите поле в схему (`*_schema()`) и значение по умолчанию (`*_defaults()`). Форма и сохранение появятся сами.
- **Новый шорткод.** Добавьте его в файл нужного раздела, стили в `blocks.css`, поведение в `front.js`. Если шорткод тяжёлый, допишите его в `mem_sc_cache_tags()` (`speed/shortcode-cache.php`).
- **Другой вид блока из темы.**
  - Переопределите правила в `content.css` темы.
  - Чтобы отключить стили плагина целиком: `add_filter('mem_core_blocks_css', '__return_false');`.
- **Сжатые файлы.** После правки `blocks.css`, `front.js` или стилей и скриптов темы сжатая `.min`-копия пересоздаётся сама при следующем открытии страницы (`speed/auto-minify.php`). Отключается в «Мемориал → Скорость».

## Кэш

- **Кэш страниц.** Лежит в `wp-content/cache/memorial/pages/`. Отдаётся только посетителям без входа в админку. Очищается сам при любой правке.
- **Кэш блоков.** Лежит в `wp-content/cache/memorial/blocks/`.
- **Очистка вручную.** «Мемориал → Скорость → Очистить кэш» или пункт «Очистить кэш» в верхней панели.
- **Если на сайте уже стоит другой плагин кэширования страниц** (LiteSpeed Cache, WP Super Cache…), свой кэш страниц не включается.
