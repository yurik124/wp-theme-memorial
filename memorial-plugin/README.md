# Memorial Plugin — функционал сайта «Мемориал»

> До 2.0 плагин назывался Memorial Core (папка `memorial-core`). Префикс кода — `memorial_plugin_`; имена настроек, полей и шорткодов в базе (`mem_…`) прежние.

Плагин отвечает за **что сайт умеет**, тема Memorial Modern отвечает за **как сайт выглядит**.
Тема и без плагина выглядит полностью: шапка, логотип, меню, подвал, страницы, оформление. Плагин добавляет к ним данные и блоки: контакты, каталог, цены, отзывы, блоки главной страницы и так далее.
Плагин работает только с темой версии 3.0 и новее. Со старой темой он ничего не подключает, поэтому сайт не ломается.

| `assets/…` (остальное) | Стили и скрипты админки | — |

## Как поменять

- **Новая настройка.** Допишите поле в схему (`*_schema()`) и значение по умолчанию (`*_defaults()`). Форма и сохранение появятся сами.
- **Новый шорткод.** Добавьте его в файл нужного раздела, стили в `blocks.css`, поведение — хранилище Interactivity API в `assets/js/view/blocks.js` и директивы `data-wp-*` в разметке.
- **Другой вид блока из темы.**
  - Переопределите правила в `content.css` темы.
  - Чтобы отключить стили плагина целиком: `add_filter('memorial_plugin_blocks_css', '__return_false');`.
- **Сжатые файлы.** После правки `blocks.css` или стилей и скриптов темы пересоберите `.min`-копию: `php tools/minify.php путь/к/файлу` (CI проверяет, что копии свежие).

## Кэш и скорость

Модули скорости (кэш страниц и блоков, сжатие HTML, относительные адреса, пересжатие фото в WebP, автосжатие CSS/JS) удалены в 2.0.0: кэш страниц и сжатие делает хостинг, фото WordPress 7.1 обрабатывает при загрузке сам. При первом входе в админку после обновления плагин убирает за собой правила «Memorial cache» из `.htaccess` и папку `wp-content/cache/memorial/`. Настройка `mem_speed` остаётся до 2.1.0 для отката.

## 2.0.0 — блоковая архитектура (WordPress 7.1)
- **Блоки.** Шорткоды заменены блоками; шорткоды внутри текста стали «значениями сайта»; плавающие элементы встают в подвал сами (Block Hooks).
- **Админка.**
  - Экраны на DataViews / DataForm и `@wordpress/admin-ui`.
  - 12 способностей (Abilities API) и команды палитры Ctrl/Cmd + K.
- **Сайт.**
  - Поведение блоков — Interactivity API: только на страницах с блоками.
  - Стили — пресеты темы с запасными значениями.
- **Безопасность, доступность, тесты.**
  - IP в заявках не хранится; ограничения частоты.
  - WCAG 2.2 AA: контраст, фокус, анимации.
  - PHPUnit и e2e.
- **Переводы и удаление.**
  - Строки на английском, русский перевод в `languages/`.
  - `uninstall.php`: по умолчанию содержимое остаётся, полное удаление — по константе `MEMORIAL_PLUGIN_DELETE_DATA`.
- **Удалено.** Модули скорости и справка «Шорткоды и блоки».
- Подробно — `MIGRATION.md` в корне репозитория.
